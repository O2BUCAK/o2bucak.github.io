# o2bucak.github.io

Personal website of Ersin Özbuçak.

## Structure

- `index.html` — single-page site
- `assets/css/style.css` — design system and responsive layout
- `assets/js/main.js` — TR/EN language switching
- `assets/images/` — certificates, project images and future media

## GitHub Pages

This repository is designed to work directly with GitHub Pages. No build step is required.

1. Create `O2BUCAK.github.io` (or `o2bucak.github.io`) on GitHub.
2. Push the repository contents to the `main` branch.
3. Enable GitHub Pages from repository settings if it is not enabled automatically.
